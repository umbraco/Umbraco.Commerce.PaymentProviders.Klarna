# Upgrade to Umbraco 19

From Umbraco Commerce `[18.0.0, 18.999.999)` (CMS 18) to Umbraco Commerce `19.0.0-beta.1` (CMS `19.0.0-beta1`, tag `release-19.0.0-beta1`).
Branch `v19/topic/cms-19-upgrade` → PR into `release/19.0.0`, both cut from `main` (`9f40527`).

**Targets CMS release:** `release-19.0.0-beta1`, via Umbraco Commerce `19.0.0-beta.1` (MyGet `umbracoprereleases`, already in `NuGet.config`). The package's own version is `19.0.0-beta.1`.

The package depends only on `Umbraco.Commerce.Core` and `Flurl.Http` (its own Klarna REST client, no Klarna SDK), never on `Umbraco.Cms.*` directly, so the CMS breaking changes reach it only through Commerce. Commerce's own v19 inventory (Core repo, `docs/upgrades/v19.md`) and the Stripe provider's v19 upgrade are the sources for those.
